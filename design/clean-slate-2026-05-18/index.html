Clean-Slate Design Exploration · 2026-05-18

Ollie, redrawn from a blank slate.

A blindfolded redesign of Ollie's iOS app — driven only by what the code says the app does, not by a single pixel of how it currently looks. No existing palette, type, layout, naming, or "design DNA" was consulted.

Method: codebase read for behavior only — routes, 12 modules, ~100 logic detectors, orchestrators, the notification constitution, the event registry.
Read the full rationale: DIRECTION.md  ·  7 screens below, each a standalone iPhone-sized HTML file (390×844).

The core design bet

For a mid-spiral ADHD brain, the thought is gone in 8 seconds — so capture is not a feature you navigate to, it is the floor you stand on. A persistent catch-dock on every screen, a 3-tab nav (Now · Noticed · Safe), and the 12 life domains demoted from a front-page grid to a quiet drill-down. A calm warm-paper notebook, not a productivity cockpit.

The system, in brief

paper · ground
ink · warm near-black
amber · "it landed"
sage · "you're okay"
slate · safe surface
domain tint (×12)
Two voices. Newsreader (humanist serif) for the app's own voice — greetings, cues, patterns — so it reads as a notebook, not a tool. Inter for functional body, lists, tabular numbers.
Motion. Settle, don't bounce — a 320ms ease + 600ms amber glow on capture; a 4s breathing ring on voice; 160ms tab cross-fades.
Voice. Lowercase, factual, never chirpy, never guilt-tripping — "got it, that's in finance now" over "Great job! 🎉".
This is an exploration, not a migration plan. Its value is the contrast — see DIRECTION.md §7 "What this differs from the current app" for the honest list of bets and demotions.
